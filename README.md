# myArt-Portfolio
A personal art store and portfolio site 
an entrance page leading into a gallery of paintings and sketches, available and inquiry-ready for sale.

What it does

--A landing "entrance" page (click through to enter)

--A store page with an artist bio and a filterable gallery of paintings, sorted by different category
Built for visitors to browse and inquire about pieces


Tech stack

--HTML / CSS / JavaScript — no framework

--Custom design (parallax section, category filtering, hero imagery)


What I built

--A category-based filtering system for the painting gallery

--A parallax section for visual interest between the intro and the gallery

--Custom layout and typography distinct from a template, matching the tone of the work

--Responsive image handling for artwork photography
